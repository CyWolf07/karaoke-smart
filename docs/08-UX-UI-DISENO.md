# 08 · UX/UI

- **Tokens:** `@ks/design-tokens`. Fondo `#0a0a0b`, superficies `#141416` y `#1d1d21`, acento verde `#1ed760`, peligro `#ff4d5e`.
- **Botones:** de pastilla, altura mínima 44 px (56 px en acciones principales).
- **Tipografía:** Inter o la del sistema.
- **Regla de las 3 interacciones:** conectar (escanear el QR), buscar, seleccionar y cantar.
- **Sin botones decorativos:** todo control visible ejecuta una acción real o no se muestra.

| Dispositivo | Prioridad                                                                |
| ----------- | ------------------------------------------------------------------------ |
| TV          | Letra grande, QR siempre visible, controles ocultos en modo presentación |
| Computador  | Panel con reproductor, cola y mezclador                                  |
| Celular     | Buscar, cola, botón de micrófono grande y estado de conexión             |
| Tablet      | Mezcla de celular y computador                                           |
